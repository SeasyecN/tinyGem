# rust-cloud-music-client

基于 Rust 构建的网易云音乐非官方桌面客户端，首发面向 Windows 平台（后续跨平台支持尚未承诺）。

## 当前状态

本项目目前处于**早期规划与开发准备阶段**：
- 远端代码仓库：[GitHub](https://github.com/SeasyecN/rust-cloud-music-client)。
- 本地工作区尚未初始化 Cargo 源码工程，尚无可运行的应用实体、安装包、CI 测试或端到端验证。
- 详细的前期资料级技术调研与论证记录参见 [docs/technical-research.md](docs/technical-research.md)。

## 首版功能范围

首版计划优先完成桌面播放核心闭环，以下功能清单均处于待实现状态（统一未勾选）：

- [ ] **账号会话**：二维码扫码登录、凭据安全保存与持久化会话管理
- [ ] **歌单与检索**：用户个人歌单获取、歌曲列表展示与关键字搜索
- [ ] **播放控制**：在线流媒体播放、暂停、切歌与进度跳转（Seek）
- [ ] **信息呈现**：歌曲元数据解析、专辑封面加载与滚动歌词同步
- [ ] **系统集成**：Windows 系统托盘常驻与系统媒体传输控制（SMTC）
- [ ] **打包分发**：Windows 原生安装包制作与分发流程验证

## 暂定技术栈

以下技术路线仅作为优先概念验证（POC）的探索方案，所有依赖库均未在项目中正式安装或固定：

| 层次 | 暂定组件 | 角色与待验证重点 |
| :--- | :--- | :--- |
| **GUI 框架** | GPUI + GPUI Kit | GPU 加速自绘界面；GPUI Kit 由 Longbridge 维护并重导出配套 GPUI，需重点验证 Windows 平台交互及中文输入法（IME）支持 |
| **异步运行时与网络** | Tokio + reqwest + serde | 负责异步 I/O、HTTP 请求与 JSON 序列化；需处理 Tokio 运行时与 GPUI 执行器之间的消息通信 |
| **音频流与播放** | rodio + stream-download | 优先 POC 路线；使用 stream-download 适配 HTTP Range 请求与缓存，驱动 rodio 进行在线流式播放与 Seek |
| **接口接入** | 待评估 Rust API 库 | 候选包含开源社区网易云 Rust API 封装，需实际验证接口可用性并核实许可证条款，目前未选定最终依赖 |
| **本地元数据** | SQLite (`rusqlite`) | 用于持久化歌单元数据、播放历史索引及本地缓存元数据 |
| **凭据安全** | keyring | 调用系统安全凭据存储保存登录会话，避免在本地明文留存 Cookie |
| **后续系统扩展** | souvlaki + tray-icon | 接入 Windows 媒体会话控制（HWND / SMTC）与托盘事件循环 |

## 验证路线

为控制架构复杂度与技术风险，项目将严格按照先后次序进行分步验证，不预估交付工期：

1. **第一阶段：Windows GUI 基础与输入验证**  
   验证 GPUI 在 Windows 下的窗口创建、基础控件渲染、事件响应以及中文输入法（IME）正常输入。
2. **第二阶段：账号链路与播放 URL 获取**  
   验证扫码登录全流程、安全凭据存取、个人歌单拉取，以及有效临时音频播放 URL 的获取与鉴权。
3. **第三阶段：在线流式播放与 Seek 验证**  
   使用 `rodio + stream-download` 验证真实网络音频流缓冲、网络抖动应对、拖动进度（Seek）、切歌及资源释放。
4. **第四阶段：完整界面与系统集成**  
   验证通过后，扩展完整歌单、搜索和歌词界面，并集成 Windows 系统托盘与系统媒体快捷控制。

## 开发与运行说明

当前项目尚未创建 Cargo 工程结构，本地无任何可编译源码，因此暂不提供 `cargo run`、`cargo build` 或安装指令。具体的环境要求、配置说明与构建命令将在第一阶段验证代码落地后在此更新。
